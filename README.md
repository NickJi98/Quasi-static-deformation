# Quasi-Static Deformation Modeling

Modeling the quasi-static deformation of a layered elastic medium under surface loading using the **Propagator Matrix Method**.

**Author:** Qing Ji, Stanford University  (qingji@stanford.edu)

---

## Overview
This repository contains MATLAB scripts and functions for modeling the deformation of a layered elastic medium under static or quasi-static loading at the surface. The solution is obtained via the **Propagator Matrix Method**.

Two surface load types are supported:
- **Normal pressure loading** — solved by the **P-SV system**
- **Horizontal traction loading** — the in-plane traction component drives the **P-SV system** (through the shear-traction boundary condition), while the transverse component drives the **SH system**

The P-SV and SH systems are implemented as separate pipelines, so each can be used individually. For a general horizontal traction load, run both and superpose the results field by field (see `main_example_traction.m`).

---

## Requirements
- MATLAB R202x or later
- No additional toolboxes required.  
  The propagator loops are vectorized over wavenumber and the time loop is a
  plain `for`; both were measured faster than the `parfor` versions they
  replaced, so the Parallel Computing Toolbox is no longer needed. For a very
  long time series on a many-core machine, changing `for it = 1:Nt` back to
  `parfor it` in `calc_layer.m` / `calc_layer_sh.m` may pay off again.

## Repository Structure

### 1. Scripts
- **`main_example.m`** — Example workflow for pressure loading (P-SV system)
- **`main_example_traction.m`** — Example workflow for horizontal traction loading (P-SV + SH systems)
- **`test_Boussinesq.m`, `test_Sorrells.m`** — Benchmark for Boussinesq and Sorrells problems (point load and pressure wave applied at the surface of elastic halfspace)
- **`test_Cerruti.m`, `test_Sorrells_shear.m`** — Benchmark for Cerruti problem and the Sorrells-type problem under shear traction (horizontal point load and shear traction wave applied at the surface of elastic halfspace)

### 2. MATLAB Functions (`./src`)
- **`qs_model.m`**, **`solve_ds.m`**, **`calc_layer.m`** — Core propagator matrix method (P-SV system). Input struct `src` takes the surface pressure `pp` and, optionally, the horizontal traction components `tx`, `ty` (their in-plane part enters the boundary condition)
- **`qs_model_sh.m`**, **`solve_ds_sh.m`**, **`calc_layer_sh.m`** — Core propagator matrix method (SH system). Input struct `src` takes the horizontal traction components `tx`, `ty` (only their transverse part contributes)
- **`create_model.m`** — Build the layered `elast_prop` from a **continuous** depth profile, given either as a struct of function handles (`rho`, `vp`, `vs` of depth) or as a matrix `[depth, rho, vp, vs]`. Each layer takes the profile value at its midpoint, which is second-order accurate in layer thickness (halving the thickness quarters the error) rather than first-order as top-of-layer sampling would be. Optional `param` fields: `grading` to thin the layers toward the surface, `halfspace` to set the bottom halfspace explicitly, `method` for the interpolation of a tabulated profile
- **`create_psfc.m`** — Example surface pressure loading (Gaussian, pressure wave, turbulent pressure, Delta load)
- **`create_tsfc.m`** — Example surface horizontal traction loading (Gaussian, traction wave, Delta load) with a traction azimuth parameter `taz`
- **`calc_boussinesq.m`**, **`calc_sorrells.m`** — Analytical benchmark solutions for pressure loading
- **`calc_cerruti.m`**, **`calc_sorrells_shear.m`** — Analytical benchmark solutions for horizontal traction loading

### 3. Data (`./data`)
- **`rwb_cb.mat`** — Red-white-blue colorbar  
- **`vel_model.csv`** — Example layered medium over halfspace  
- **`cm1out.nc`** — Turbulent pressure field from large eddy simulation  
  *(Download: [Google Drive link](https://drive.google.com/file/d/19DOqOyQnbwYKHG0U1_NNDzsCQnU6Bwfq/view?usp=sharing))*

### 4. Documentation (`./latex`)
- **`Propagator_Matrix.tex`**, **`refs.bib`**, **`Figures/`** — LaTeX source of the method documentation, extended with the SH system and the shear-traction benchmarks. The included `Method.pdf` is the original (P-SV only) version; recompile the LaTeX source (e.g., `pdflatex` + `bibtex`, or Overleaf) to obtain the updated PDF. The benchmark figures `Cerruti_*.png` and `Sorrells_shear.png` are generated by `test_Cerruti.m` and `test_Sorrells_shear.m`.

## Notes

The propagator matrix method uses a spatial horizontal Fourier transform, making it ideal for **periodic loading**.  
For concentrated loads, set the spatial domain much larger than the loaded area.

The solution neglects the zero-wavenumber component (`k = 0`). For horizontal traction loading this removes the rigid horizontal translation, so concentrated-load benchmarks are compared after removing the domain-averaged mean. Details of the propagator matrix method can be found in [Method.pdf](./Method.pdf) and the extended LaTeX source in [./latex](./latex).
